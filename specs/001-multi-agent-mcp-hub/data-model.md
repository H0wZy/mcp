# Data Model: Multi-Agent MCP Hub & Go CLI

This document specifies the core entities, data structures, and state transitions for the H0wZy/mcp ecosystem.

---

## 1. Entities

### `AgentCLI`
Represents an AI developer tool detected on the local workstation.

| Field | Type | Description |
| :--- | :--- | :--- |
| `Name` | `string` | Identifier (`claude`, `codex`, `agy`) |
| `DisplayName` | `string` | Human-readable name (`Claude Code`, `OpenAI Codex CLI`, `Google Antigravity`) |
| `BinaryPath` | `string` | Absolute path to the resolved executable |
| `Version` | `string` | Detected version string (e.g. `v0.154.0`) |
| `IsInstalled` | `boolean` | True if executable exists and is accessible |
| `IsHealthy` | `boolean` | True if CLI responds to probe/ping command |
| `HealthMessage` | `string` | Diagnostic notes or authentication hints |

---

### `BridgeRegistration`
Represents the configuration required to attach an MCP server to a host agent.

| Field | Type | Description |
| :--- | :--- | :--- |
| `Host` | `string` | The client CLI receiving the tool (`claude`, `codex`, `agy`) |
| `ServerName` | `string` | Name of the registered MCP server (`antigravity`, `codex`, `claude`) |
| `Scope` | `enum` | Scope of the configuration: `user` (global) or `project` (local) |
| `ConfigFile` | `string` | Path to the affected config (`~/.claude.json`, `config.toml`, etc.) |
| `Command` | `string` | Command to execute (e.g. `node`) |
| `Args` | `string[]` | Command line arguments pointing to the local server entrypoint |
| `Env` | `map[string]string`| Optional environment overrides |

---

### `MCPToolDefinition`
Declares a capability exposed by an MCP server.

| Field | Type | Description |
| :--- | :--- | :--- |
| `Name` | `string` | Tool name (e.g. `ask_antigravity`, `ask_codex`) |
| `Description` | `string` | Semantic explanation presented to the host model |
| `InputSchema` | `object` | JSON Schema specifying parameters (`prompt`, `paths`, `model`) |
| `Handler` | `function` | Async execution function executing the target CLI |

---

### `MCPToolCallResponse`
Standard response format delivered over stdio to the host agent.

| Field | Type | Description |
| :--- | :--- | :--- |
| `Content` | `Array<{ type: "text", text: string }>` | Text content generated by target model or error text |
| `IsError` | `boolean` | True if an operational or quota error occurred |

---

## 2. State Transitions

### Bridge Lifecycle

```text
[ Not Installed ]
       │
       ▼ (h0wzy-mcp / h0wzy-mcp install)
[ Detected & Selected ]
       │
       ▼ (config write & probe)
[ Registered & Active ] ◄──┐ (re-probed by h0wzy-mcp doctor)
       │                   │
       ▼                   │
[ Broken / Quota Exceeded ]─┘
       │
       ▼ (h0wzy-mcp remove)
[ Unregistered / Clean ]
```

1. **Not Installed**: Host configuration contains no reference to the server.
2. **Detected & Selected**: Go CLI identifies the host CLI and user approves integration.
3. **Registered & Active**: Host config updated with direct local Node execution path.
4. **Broken / Quota Exceeded**: Health check fails or tool call captures HTTP 429; non-fatal warning generated.
5. **Unregistered**: Entry cleanly removed from host configuration without touching unrelated keys.
